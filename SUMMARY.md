# 📊 Полный Summary проекта «Family Budget Bot»

Создано и полностью готово к использованию production-ready решение **Family Budget Bot** — приватный Telegram-бот и Telegram Mini Web App для учета семейного бюджета двух пользователей.

---

## 🏗 Архитектурный стек и технологии

| Компонент | Технологии | Назначение |
| :--- | :--- | :--- |
| **Backend & Web API** | Python 3.12, FastAPI, Uvicorn | REST API, обслуживание Mini App, обработка Webhook |
| **Telegram Bot Engine** | `aiogram 3.x` (ParseMode.HTML) | Асинхронный бот с интерактивными кнопками и FSM-мастерами |
| **База данных** | SQLite (WAL mode), SQLAlchemy 2.x async (`aiosqlite`) | Локальное, быстрое и отказоустойчивое хранение данных |
| **Распознавание речи (STT)** | `faster-whisper` (`int8`), `ffmpeg` | Локальная расшифровка голоса без внешних облаков и с автоудалением аудио |
| **Парсер операций** | Rule-based + OpenRouter API / Ollama | Извлечение типа, суммы, даты и категории. 100% фолбек на гибридные правила |
| **Математика целей** | Чистый Python (Compound Interest) | Точный расчёт будущей стоимости, ежемесячных взносов и сроков накопления |
| **Mini Web App** | Jinja2, Vanilla CSS (Glassmorphism), Vanilla JS | Адаптивный мобильный интерфейс, интегрированный в Telegram |
| **Контейнеризация** | Docker, Docker Compose, Caddy | Развёртывание в один клик с автоматическим HTTPS |

## 🎯 Реализованный функционал

### 1. Ввод и подтверждение операций
- **Текстовый и голосовой ввод**: Поддержка распознавания фраз вида:
  - `«купил кофе за 250 рублей»` (Расход 250 ₽, Категория: *Кафе и рестораны*)
  - `«получил зарплату 80к»` (Доход 80 000 ₽, Категория: *Зарплата*)
  - `«отложил 5000 на отпуск»` (Пополнение цели *Отпуск*)
  - `«перевёл 10000 с карты на счёт»` (Перевод)
- **Карточка подтверждения**: Каждая операция перед сохранением показывает черновик с кнопками:
  - `✅ Подтвердить`
  - `🏷 Изменить категорию`
  - `✏️ Исправить текстом`
  - `❌ Отмена`
- **Строгий лимит валюты**: Поддерживаются только рубли (`RUB`). На попытки ввода валют ($ / € / USD / EUR) бот отвечает: *"Пока я поддерживаю только рубли"*.

### 2. Финансовые цели и накопления (`/goals`, `/goal_new`)
- **Пошаговый мастер создания цели**:
  1. Название цели (например: *Отпуск*, *Техника*, *Подушка безопасности*).
  2. Целевая сумма.
  3. Сколько уже накоплено.
  4. Срок в месяцах.
  5. Процентная ставка по вкладу / накопительному счёту (APY %).
- **Точные финансовые расчёты**:
  - Ежемесячный необходимый взнос: $PMT = \frac{(Target - Current \cdot (1+r)^n) \cdot r}{(1+r)^n - 1}$
  - Прогноз накоплений с учётом процентов (Compound Interest).

### 3. Персональный советник (`/advice`)
- **Детерминированный движок рекомендаций**: Анализирует последние 30 дней и предыдущий период.
- Проверяет:
  - Норму сбережений (если $< 10\%$, предлагает автоперевод 5% от дохода).
  - Подписки (если $> 500$ ₽/мес, предлагает ревизию).
  - Аномальный рост категорий расходов ($> 20\%$).
  - Наличие подушки безопасности и сбалансированность взносов на цели.
- Опциональная полировка текста через **OpenRouter API** или **Ollama** без изменения чисел.

### 4. Telegram Mini Web App (`/open_app`)
- **Маршрут `/app`**: Загружает мобильный интерфейс.
- Отображает:
  - Текущий баланс (Стартовый баланс + Доходы - Расходы).
  - Доходы, расходы и свободный остаток за текущий месяц.
  - Норму сбережений (%).
  - Топ-3 категории расходов за месяц.
  - Интерактивные карточки активных целей с progress-bar.
  - Последние 20 операций.
- **Безопасность**: Защита эндпоинтов `/api/*` через валидацию HMAC-SHA256 подписи `initData` Telegram.

### 5. Безопасность и управление данными
- **Доступ строго по Allowlist**: Бот и Web App отклоняют всех пользователей, чьи Telegram ID не внесены в `ALLOWED_TELEGRAM_IDS`.
- **Экспорт данных (`/export`)**: Выгрузка файлов `transactions.csv` и `goals.csv`.
- **Полная очистка (`/delete_all`)**: Двухшаговое подтверждение inline-кнопками для сброса истории при сохранении зарегистрированных пользователей.

## ⚡ Оптимизации для слабых VPS (1 vCPU / 2 GB RAM)

- **OpenRouter API (`LLM_PROVIDER=openrouter`)**: Вынесение нейросетевого парсинга в облако без нагрузки на CPU/ОЗУ сервера.
- **Нулевой fallback (`LLM_PROVIDER=rule_based`)**: Полная автономная работа парсера и советника, потребляющая всего **~80 МБ ОЗУ**.
- **Лёгкий STT (`faster-whisper` int8)**: Автоматическая очистка временных аудиофайлов и ограничение длины голоса (до 2 минут).

## 🔧 Решённые системные нюансы при отладке

1. **Форматирование `.env`**: Добавлена гибкая обработка `ALLOWED_TELEGRAM_IDS` как для списков через запятую (`123,456`), так и для JSON-массивов (`[123, 456]`).
2. **Совместимость с aiogram 3.7+**: Обновлена инициализация бота на `DefaultBotProperties`.
3. **Безопасность разметки Telegram (HTML mode)**: Перевод с Markdown на `ParseMode.HTML`, исключающий падения при наличии символов подчёркивания в командах (`/goal_new`, `/set_balance`, `/delete_all`).
4. **Обработка HTTP/HTTPS ссылок**: Реализован адаптивный режим: при локальной разработке (`http://localhost:8000`) выводится информационная кнопка, а при деплое с HTTPS активируется встроенный WebApp.
